# 🚀 Git Setup & Push to GitHub from Scratch

```bash
# Step 1: Create and navigate to your project folder
mkdir MyProject
cd MyProject

# Step 2: Initialize Git
git init

# Step 3: (Optional) Create a README file
echo "# MyProject" > README.md

# Step 4: Add all files to staging
git add .

# Step 5: Commit the files
git commit -m "Initial commit"

# Step 6: Add GitHub repository as remote
git remote add origin https://github.com/<your-username>/<repo-name>.git

# Step 7: Rename default branch to 'main' (if not already)
git branch -M main

# Step 8: Push to GitHub
git push -u origin main
